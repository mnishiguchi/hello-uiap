### OLED

販売コード `112031` は 128×64、I2C、SSD1315 のモジュールで、電源電圧は
3～5 V です。このゲームは SSD1306/SSD1315 を直接制御し、起動時に I2C
アドレス `0x3C` と `0x3D` を順番に探します。

電源は UIAPduino の `3V3` に接続します。

```text
OLED VDD  -> 3V3
OLED GND  -> GND
OLED SDA  -> D3 / PC1
OLED SCL  -> D4 / PC2
```

### ボタン

販売コード `108214` はブレッドボードで使える 2 本足のモーメンタリー
タクトスイッチです。同じものを 3 個購入します。色はゲームの動作に影響しないため、
赤、緑、白など同形状の色違いへ変更しても構いません。

各ボタンは GPIO と GND の間に接続します。スケッチが内部プルアップを使うので、
外付け抵抗は不要です。

```text
D8  / PC6 -> LEFT   -> GND
D9  / PC7 -> RIGHT  -> GND
D10 / PD0 -> ACTION -> GND
```

### 圧電スピーカー

販売コード `104118` は、信号を与えたときだけ鳴る他励式の圧電スピーカーです。
ゲーム側が周波数の異なる矩形波を生成するため、この種類を使用します。

電源をつなぐだけで一定音を出す電子ブザーや自励式ブザーへ置き換えると、
ゲームの高音、低音を鳴らし分けられません。

```text
圧電スピーカー + -> D5 / PC3
圧電スピーカー - -> GND
```

## 必要に応じて追加する部品

| 部品 | 販売コード | 数量 | 価格 | 必要になる場合 |
| --- | --- | ---: | ---: | --- |
| [USB 2.0 Type-A－Type-C 通信ケーブル 1.5 m](https://akizukidenshi.com/catalog/g/g113563) | `113563` | 1 | 130 円 | データ通信対応ケーブルを持っていない |
| [細ピンヘッダー 1×40](https://akizukidenshi.com/catalog/g/g106631) | `106631` | 1 | 45 円 | UIAPduino にブレッドボード用の足が付いていない |

USB ケーブルは給電専用品ではなく、必ずデータ通信対応品を使います。UIAPduino の
公式資料では、ケーブルが長い場合に書き込みが不安定になる例も報告されています。
書き込みエラーが発生する場合は、短いケーブルや別の USB ポートも試します。

ピンヘッダーは 12 ピンを 2 本切り出して UIAPduino の左右へはんだ付けします。
すでにコンスルーやピンヘッダーが付いているボードでは購入不要です。
