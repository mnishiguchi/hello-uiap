## Arduino IDE 導入方針

最初は AppImage を試したが、環境側で `/dev/fuse` が使えなかった。その後
Flatpak 版も試し、コンパイル自体はできたが、sandbox がホストの `plugdev`
補助グループを引き継がなかった。そのため raw-HID ベースの `minichlink`
アップローダーが、追加の udev 調整なしではボードへアクセスできなかった。

設定を最小に保つため、Flatpak アプリ、ユーザー Flathub remote、暫定ランチャー
は削除した。代わりに、確認済みの公式 ZIP 版を使って Arduino IDE を導入した。

```text
~/Applications/arduino-ide-2.3.10
```

ターミナル用コマンド名と Cinnamon メニュー項目名は、どちらも `arduino-ide`。

## USB トラブルメモ

- UIAPduino の書き込みはシリアルではなく USB HID を使う。Arduino IDE に
  **not connected** と出ても正常。
- ブートローダー時の USB 識別子は `1209:b803`, product `32V003`。
- 失敗時には kernel 側で USB protocol error `-71` が出ており、`minichlink`
  起動時に使える programmer が見つからなかった。
- ブートローダー接続をやり直したところ、bootstrap 書き込みは成功した。
- 同じ症状が再発したら、別の USB ポート、USB 2.0 ハブ、短いデータ対応ケーブル
  を試す。

## 次の確認事項

Seamless Switch が USB を抜かずに使えるか確認する。

1. bootstrap 書き込み済みのスケッチを 1 回リセットして実行する。
2. USB はつないだままにする。
3. 点滅周期が見て分かる程度に変わるようスケッチを修正して保存する。
4. 1 回リセットして USB write-standby モードへ入る。
5. **Upload** を押す。
6. `Image written.` を待つ。
7. 1 回リセットして新しいスケッチを実行する。
8. 点滅周期が変わったことを確認する。

Seamless Switch で不要になるのは USB の抜き差しだけ。書き込み前の 1 回と、
実行開始の 1 回のリセットは引き続き必要。
