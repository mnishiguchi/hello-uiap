## Arduino IDE installation decision

The AppImage was initially tested, but `/dev/fuse` was unavailable. A Flatpak
installation was then tested and compiled successfully, but its sandbox did
not preserve the host's `plugdev` supplementary group. This prevented the
raw-HID `minichlink` uploader from accessing the board without an additional
udev customization.

To keep the setup minimal, the Flatpak app, user Flathub remote, and temporary
launcher were removed. Arduino IDE was installed from the verified official
ZIP instead:

```text
~/Applications/arduino-ide-2.3.10
```

The terminal command and Cinnamon menu entry are both named `arduino-ide`.

## USB troubleshooting

- UIAPduino upload uses USB HID, not a serial port. Arduino IDE showing
  **not connected** is expected.
- The bootloader identifies as USB `1209:b803`, product `32V003`.
- Failed attempts showed kernel USB protocol error `-71` and no programmer was
  available when `minichlink` started.
- Retrying the bootloader connection resulted in a successful bootstrap
  upload.
- If the error returns, use a different USB port or a USB 2.0 hub and a short,
  known-good data cable.
