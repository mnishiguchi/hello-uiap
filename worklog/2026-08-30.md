# UIAP Worklog - 2026-08-30

## CH32V006 blink

- 接続したボードは `1209:b806` として認識された。これは UIAPduino のオンボード RVSWDIO programmer。
- 公式の V006 V1.1 手順が `ch32fun` と `minichlink` 前提であることを確認した。Arduino IDE は公式には未対応。
- 現行の `ch32fun` を `~/Projects/uiap/hello-uiap/ch32fun` へ clone した。
- 現行 `minichlink` のビルドに成功した。
- `~/Projects/uiap/hello-uiap/ch32v006_ch32fun_blink` を作成した。
- 内蔵 LED を `PC3` で設定し、オンボードデバッガへ干渉し得る `PC0` は意図的に使わなかった。
- `CH32V006` 向けビルド結果は flash 664 bytes, static RAM 0 bytes。
- programmer selector `1209:b806` と `funprog` を使って書き込み成功。
- テストパターンは 150 ms 点滅 2 回のあと 1000 ms 停止。

## 再実行手順

```sh
cd ~/Projects/uiap/hello-uiap/ch32v006_ch32fun_blink
make
make flash
```

リセットボタンのタイミング合わせは不要。

## 実験的 Arduino 手順

インストール済みの UIAPduino core `1.0.42` には `CH32V006K8` 用 Arduino variant
が含まれているが、UIAP パッケージの `boards.txt` からは選べない。そこで
**Pro Micro CH32V006 (Experimental)** エントリをローカル追加し、さらに
`1209:b806` の programmer を使う V006 専用 upload recipe を加えた。

Arduino スケッチ:

```text
~/Projects/uiap/hello-uiap/ch32v006_arduino_blink/ch32v006_arduino_blink.ino
```

公式の UIAP V1.1 ドキュメントでは、依然として Arduino IDE は未対応。したがって
この構成は、まずは基本的な GPIO とタイミングが動くことを確認するためのものと
捉える。

コンパイルと書き込み結果:

- Flash 使用量: 8,280 / 63,488 bytes
- RAM 使用量: 556 / 8,192 bytes
- `minichlink` は CH32V006 を検出し、`Image written.` を報告した
- リセットボタンのタイミング合わせは不要だった
- 実機確認成功: 内蔵 LED は 150 ms 点滅 2 回のあと 1000 ms 停止を繰り返した

## Arduino IDE で再実行

1. `arduino-ide` で Arduino IDE を起動する。
2. **UIAPduino > Pro Micro CH32V006 (Experimental)** を選ぶ。
3. `ch32v006_arduino_blink/ch32v006_arduino_blink.ino` を開く。
4. **Upload** を押す。リセットボタンは不要。

結果: Arduino 風の `setup()`, `loop()`, `pinMode()`, `digitalWrite()`, `delay()`
が UIAPduino Pro Micro CH32V006 V1.1 で動作することを確認した。
