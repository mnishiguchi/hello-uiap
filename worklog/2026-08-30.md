# UIAP Worklog - 2026-08-30

## CH32V006 blink

- Connected board enumerated as `1209:b806` (UIAPduino onboard RVSWDIO programmer).
- Confirmed the official V006 V1.1 workflow uses `ch32fun` and `minichlink`;
  Arduino IDE is not officially supported.
- Cloned current `ch32fun` to `~/Projects/uiap/hello-uiap/ch32fun`.
- Built the current `minichlink` successfully.
- Created `~/Projects/uiap/hello-uiap/ch32v006_ch32fun_blink`.
- Configured the built-in LED on `PC3`; deliberately avoided `PC0` because it can interfere with the onboard debugger.
- Built for `CH32V006`: 664 bytes flash, 0 bytes static RAM.
- Flashed successfully using programmer selector `1209:b806` and `funprog`.
- Test pattern: two 150 ms flashes followed by a 1000 ms pause.

## Experimental Arduino workflow

The installed UIAPduino core `1.0.42` contains a `CH32V006K8` Arduino variant,
but the UIAP package does not expose it in `boards.txt`. Added a local
**Pro Micro CH32V006 (Experimental)** entry and a V006-only upload recipe that
uses the working project build of `minichlink` with programmer USB ID
`1209:b806`.

Arduino sketch:

```text
~/Projects/uiap/hello-uiap/ch32v006_arduino_blink/ch32v006_arduino_blink.ino
```

The official UIAP V1.1 documentation still lists Arduino IDE as unsupported,
so this setup should initially be treated as basic GPIO/timing support rather
than full board compatibility.

Compile and upload result:

- Flash used: 8,280 of 63,488 bytes
- RAM used: 556 of 8,192 bytes
- `minichlink` detected the CH32V006 and reported `Image written.`
- No reset-button timing was required
- Hardware verification succeeded: the onboard LED repeats two 150 ms flashes
  followed by a 1000 ms pause

## Repeat with Arduino IDE

1. Start Arduino IDE with `arduino-ide`.
2. Select **UIAPduino > Pro Micro CH32V006 (Experimental)**.
3. Open `ch32v006_arduino_blink/ch32v006_arduino_blink.ino`.
4. Click **Upload**. No reset-button press is needed.

Result: Arduino-style `setup()`, `loop()`, `pinMode()`, `digitalWrite()`, and
`delay()` are verified working on the UIAPduino Pro Micro CH32V006 V1.1.
